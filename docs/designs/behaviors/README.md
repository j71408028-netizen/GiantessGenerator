# 行为包：给世界包换一套「玩法内核」

> 面向玩家与世界包使用者。想自己写行为包，看 [dev-guide.md](dev-guide.md)。

行为包（Behavior Pack）是世界包可选携带的一小段 Python 代码。世界包激活期间，
它会改掉程序里一些原本固定的算法——比如身高怎么抽、尺寸用什么单位显示、
离线恢复怎么算、报告里地标和描述怎么配对。

可以把它理解成世界包的「规则层」：世界包里的地标、描述、副本方案是**内容**，
行为包改变的是程序处理这些内容的**方式**。

## 玩家能感知到什么

| 行为包改动的部分 | 你可能会看到 |
|---|---|
| 角色创建 | 身高生成的分布与「意愿」判定方式变化 |
| 尺寸显示 | 单位从米 / 千米换成英尺 / 英里（随包自带的 `imperial_units` 示例） |
| 坐标与行动点 | 报告后坐标的推进、行动点回复与消耗的手感变化 |
| 离线恢复 | 回到程序时离线结算的恢复量、坐标变化与明细文案 |
| 报告选取 | 地标与描述的配对、事件描述的挑选、伤亡与耐久估算 |
| 档案文本 | 「作息与活动范围观察」、实时提示的措辞 |
| 聊天 | 通讯媒介、世界背景、话题候选与措辞、回复节奏与主动搭话门槛 |

它**不会**改写角色已经成立的东西：名字、性格、学到的作息与活动习惯、履历。
世界包对角色出身参数的影响只发生在**创建角色时**，已有角色不会因为启停
世界包而性情大变。

## 怎么用

- 行为包**不能单独启用**，只能随世界包一起激活。在「设置 → 世界包」中激活、
  停用或解散世界包即可。
- 一个世界包最多携带**一个**行为包。行为包随 `<world_id>.world.zip` 分发，
  不需要单独安装。
- 激活后，导航栏底部的世界包信息会显示「行为已更改 N 项」；把鼠标停在上面，
  可以展开接管清单、行为包 API 版本与警告。
- 停用、解散或切换到别的世界包后，覆盖立即清空、恢复默认行为，不需要重启。
- 解散世界包时，里面的行为包会自动转存回 `data/static/behaviors/`，不会丢。
- 进入副本时，副本进程也会加载同一个行为包，副本内的行为与主界面一致。

## 安全提醒

行为包本质是 Python 代码，激活时会在你的电脑上执行。只应激活来自可信来源的
世界包，如同对待一般软件一样。程序不会自行联网下载或安装行为包。

如果某个行为模块加载失败或注册不合法，只有那一条会被跳过并记入诊断
（导航栏显示「⚠ 行为包诊断异常」），其余行为与默认行为照常工作。

## 和世界包其他资源的关系

| 世界包里的东西 | 作用 |
|---|---|
| 资源包 / 静态表 | 提供内容：地标、描述风格、副本方案、姓名、新闻、性格、身材预设…… |
| 行为包 | 提供规则：激活期间覆盖核心算法 |

内容随数据变化，规则随代码变化；世界包把两者打包在一起统一启停。
